🚨 의료 도메인 결정적 결함

스티렌정(Stillen)은 실제 동아ST의 위염 치료제입니다. Corepin의 "스타헌증"은 한국 의약품 데이터베이스에 존재하지 않는 명칭입니다. 처방전 자동 처리 시스템에서 약품명 오인식은 환자에게 잘못된 약이 조제되거나 청구 거절로 이어질 수 있는 환자 안전과 청구 정합성에 직결되는 결함입니다. 단순히 "정확도가 조금 낮다"가 아니라 의료 도메인에서 사용 가능 여부 자체가 갈리는 격차.

회전 자동 보정 (180°) 자동 감지 + 보정 → 텍스트 정방향 의미 단위로 추출 회전 보정 없음 → 단어 단위 OCR 오류 다수
Element 구조 3 elements (header + table 2개) — 환자정보·의약품 표 분리 인식 paragraph 단 1개로 페이지 전체 통합
표 구조 인식 (rowspan/colspan) HTML table — 의료기관 rowspan="4", 환자/질병분류 rowspan="2" 완벽 처리 table 카테고리 0개 — 모든 셀 데이터가 paragraph 텍스트에 흘려 들어감
체크박스 양식 (☑/□) ☑ 의료보험 / □ 의료보호 / □ 산재보험 등 체크 상태 구분 인식 체크박스 정보 일체 누락 — 어느 보험 유형인지 알 수 없음
의약품명 정확도 (3종) 3/3 정확 (도란사민 캅셀, 케토라신정, 스티렌정) 3/3 모두 오인식 — 도란사민 합썰, 케토라신장, 스타헌증(존재하지 않는 약품명)
