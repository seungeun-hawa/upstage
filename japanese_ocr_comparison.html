빨간 음영 = Corepin이 일본어를 중국어로 추론한 오인식 구간. 조사 "の"→"的" (4건), 어미 "ください"→"下午", 한자 변환 (個人→偹人, 権→榷, 偽→倘, 申請→申请, 請求→请求 등). 비한국어 입력 시 모델이 다른 언어 가중치로 추론하는 구조적 한계가 일관되게 관찰됨.

핵심 시사점

1. Corepin "한국어 전용 학습"의 실제 의미

마케팅 표현이 아니라 모델이 비한국어 입력 시 다른 언어로 추론해버리는 구조적 한계. 일본어 입력 → 중국어 추론 패턴이 조사·어미·한자 전반에 걸쳐 일관되게 발생. 일본어 신자체(請·申·個·権·満·偽)를 모두 중국어 간체자로 변환했고, 조사 "の"는 4건 모두 중국어 "的"으로, 어미 "ください"는 "下午(오후)"로 추론.

2. Upstage "Beta 지원"의 실제 의미

명세서엔 Beta로 표기했지만 실측에서 일본어 신자체·조사·어미·체크박스를 모두 보존. ocr-250904 release note에 일본어 정확도 개선 수치 공개 (scene text 89.39%→91.70%, document text 95.19%→96.72%). word/line 단위 confidence로 검토 영역 자동 식별 가능 — 손글씨 등 약점 구간도 사람 검수 워크플로우와 결합 가능.

3. 출력 구조의 본질적 격차

Upstage는 134 words + 39 lines + bbox + confidence + 페이지 메타를 제공하는 raw OCR 표준 출력. Corepin은 1개 청크에 전체 텍스트를 흘려넣는 단순 텍스트 추출 응답. 후단 RAG·자동화·검증 파이프라인 구축 가능 여부에서 격차가 본질적.
