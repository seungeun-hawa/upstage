핵심 시사점

1. 다단 레이아웃의 본질적 차이 — Reading Order의 의미

좌/우 병렬 배치된 표를 Corepin은 위→아래 순서로 읽어 좌측 표를 텍스트 fragments로 분해. Upstage는 x좌표 기반으로 좌/우 단을 구분, 부모 비교표 안의 nested table 두 개로 정확히 매핑하며 비교 의도까지 보존. 한국 공문, 약관, 재무제표, IR 자료 등 다단 레이아웃이 핵심인 문서에서 격차가 결정적으로 벌어짐. 단순히 "표 인식률"이 아니라 2D 공간 이해의 본질적 차이.

2. 플로우차트의 figure 인식 — LLM 파이프라인 가치

Corepin은 도식을 평탄한 표들로 분해하여 박스 간 연결 관계와 방향성 완전 손실. Upstage는 figure 카테고리로 인식하고 도식 유형 자동 분류(diagram/flowchart/organizational chart) + 영문 상세 설명 텍스트 + 원본 base64 이미지까지 응답에 포함. RAG 파이프라인에서 LLM이 도식의 의미를 즉시 이해할 수 있음. IR 자료의 조직도, 약관의 청구 흐름도, 학술 논문의 다이어그램 등에서 결정적 격차.

3. bbox 좌표의 비즈니스 가치 — 자동화 후처리 가능 여부

Upstage는 모든 element에 4-vertex polygon 좌표 제공. RAG 답변 시 페이지 참조, 하이라이트, 영역 검출, 사용자 검증 UI 모두 가능. Corepin은 좌표 정보 일체 없음 — 자동화 후처리 불가능, 사람 검수 필수. OCR 케이스(Appendix C/D)에서 본 word/line bbox 부재와 동일한 패턴이 DP 레이어에서도 일관됨. Corepin은 "출력만 받으면 된다"는 단순 변환 시나리오에 최적화, Upstage는 "출력을 다시 가공해서 시스템에 통합한다"는 자동화 시나리오에 최적화.
