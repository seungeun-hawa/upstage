📊 차트 인식의 영업 임팩트

차트는 LLM 자동화의 핵심 데이터 소스입니다. Upstage는 차트 유형(pie/bar)을 자동 분류하고 데이터 매트릭스를 <table>로 출력하므로, 그대로 Solar/GPT에 넣어 "한국 vs 미국 격차 요약", "확산 속도 비교 시각화 재생산" 같은 작업이 가능합니다. Corepin은 차트 수치가 paragraph 안에 평탄화되어 "63.5 39.6 51.8 26.5..." 같은 숫자 나열만 남기 때문에 어느 차트·어느 축의 값인지 알 수 없습니다. 데이터 분석·금융·리서치 도메인에서 결정적인 차이.

차트 데이터 추출 데이터 매트릭스를 <table>로 변환 (한국 63.5/51.8/60.0, 미국 39.6/26.5/33.7 등 셀 단위 매핑) "63.5 39.6 51.8 26.5..." 식 숫자 나열 — 어느 축 값인지 판별 불가
차트 이미지 base64 이미지 포함 (LLM 시각 분석 즉시 가능) + bbox 좌표 이미지 데이터 일체 없음
